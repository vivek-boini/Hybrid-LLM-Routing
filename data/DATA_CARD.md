# Data Card: Mix-Instruct (llm-blender/mix-instruct)

## Dataset Overview
- **Name:** Mix-Instruct
- **Source:** HuggingFace Hub (`llm-blender/mix-instruct`)
- **License:** MIT License
- **Domain:** Instruction-following multi-model evaluation
- **Task in this Repo:** Provides real user prompts, candidate LLM responses, output token lengths, and BERTScore quality labels for edge routing.

## 1. Full Prepared Dataset (`data/mix.npz`)
Generated by streaming the real `train_data_prepared.jsonl` (first 20,000 requests) and `val_data_prepared.jsonl` (5,000 requests split into dev and test):
```bash
python -m qos.cli prepare \
  --train-path data/raw/train_data_prepared.jsonl \
  --val-path data/raw/val_data_prepared.jsonl \
  --train-n 20000 \
  --val-n 5000 \
  --tokenizer tiktoken \
  --out data/mix.npz
```

## 2. Tokenizer Evaluation: Signed Error (Bias) of Approx vs. Tiktoken
Evaluated across **64,948 real prompt and candidate response texts** in Mix-Instruct:

$$\text{Signed Difference} = \text{approx} - \text{tiktoken}$$
$$\text{Relative Signed Error} = \frac{\text{approx} - \text{tiktoken}}{\text{tiktoken}}$$

| Metric | Signed Difference (Tokens) | Relative Signed Error (%) |
| :--- | :---: | :---: |
| **Mean** | **+2.864** | **+4.26%** |
| **Median (p50)** | **+5.000** | **+8.44%** |
| **Std Dev** | 34.889 | 21.73% |
| **5th Percentile (p5)** | -14.000 | **-35.48%** |
| **95th Percentile (p95)** | +22.000 | **+25.00%** |
| **Min / Max** | -632 / +84 | -85.23% / +300.00% |

### Key Observation
The naive heuristic `approx` (`ceil(words * 1.33)`) has a net positive bias (+4.26% mean, +8.44% median) on typical natural language, but severely underestimates token count by up to 35.5% (p5) to 85.2% (min) on dense code snippets, URLs, and formatting markers. Using `--tokenizer tiktoken` gives exact BPE counts matching real LLM tokenizers.
